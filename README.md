# Алина Медведева — Creative Portfolio

Готовый **статический** сайт для GitHub Pages. Без React, Node, базы данных, платного хостинга и шага сборки. Работает на телефоне и компьютере. Фотогалерея переключает три режима, фотографии раскрываются в лайтбоксе, а видео подключаются через YouTube в один клик.

## Запуск локально

Можно открыть `index.html` двойным кликом. Для более точного поведения веб-сервера можно запустить в папке проекта:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Деплой на GitHub Pages

1. Создать на GitHub новый репозиторий, например `portfolio`.
2. Загрузить **содержимое этой папки** в корень репозитория (файл `index.html` должен быть в корне).
3. Открыть **Settings → Pages → Build and deployment**.
4. В **Source** выбрать **Deploy from a branch**, в **Branch** выбрать `main` и `/(root)`, затем **Save**.
5. Адрес будет примерно `https://USERNAME.github.io/portfolio/`. Публикация может занять несколько минут.

Файл `.nojekyll` отключает обработку Jekyll. Все ресурсы используют относительные пути, поэтому сайт работает и в корне домена, и по адресу `/portfolio/`.

## Как добавить свою фотосессию

1. Сохранить фото как `.webp` или `.jpg` в папку `assets/images/` (для веба обычно достаточно длинной стороны 1600–2400 px, избегайте фото по 10–20 МБ).
2. Открыть `js/content.js`.
3. В массиве `photoshoots` заменить демонстрационную фотосессию на свою или добавить следующую. Например:

```js
{
  id: 'autumn', number: '02', title: 'Осенний портрет',
  type: 'Портрет / lifestyle', year: '2026', demo: false,
  description: 'История фотосессии, свет, настроение, команда.',
  photos: [
    {src: 'assets/images/autumn-01.webp', alt: 'Девушка в парке', caption: '01 / Главный портрет'},
    {src: 'assets/images/autumn-02.webp', alt: 'Крупный план', caption: '02 / Деталь'}
  ]
}
```

Вставить объект через запятую после предыдущего. Три режима галереи (Editorial, Mosaic, Contact sheet) применяются автоматически к любой серии. Снимки откроются по клику во весь экран с листанием стрелками клавиатуры.

**Автор фотографий — Алина Медведева.** В галерее размещены **9 её фотографий**, сгруппированных в 3 авторские портретные серии по образам (коричневый тренч, белый топ, красный жакет). Это не утверждение о трёх отдельных коммерческих заказах. Перед публичным размещением фотографий с узнаваемыми моделями следует убедиться, что разрешение на публикацию есть.

## Как добавить YouTube

Все 8 переданных YouTube Shorts уже добавлены в `js/content.js` в массив `videos`. Для нового видео добавьте туда объект или замените `youtubeId` существующего. Например, ссылка выглядит так: `https://www.youtube.com/watch?v=AbCdEf12345`, то ID — `AbCdEf12345`. Не вставляйте полный адрес. Можно добавить любое количество видео в массив `videos`.

Встроенный плеер использует `youtube-nocookie.com` и загружается только после нажатия на Play. Это уменьшает первоначальную загрузку страницы. Для работы YouTube требуется интернет, а воспроизведение может зависеть от региона и настроек видео.

## Контакты

В том же `js/content.js` добавить свои `email`, `telegram`, `behance` и `instagram`. Пустые поля не создают неработающих ссылок.

## Структура

```text
portfolio/
├── index.html                 # разметка всех разделов
├── .nojekyll                  # статический режим GitHub Pages
├── css/style.css             # дизайн, адаптивность и галереи
├── js/content.js             # фотографии, видео и контакты — РЕДАКТИРОВАТЬ ЗДЕСЬ
├── js/main.js                # меню, галерея, лайтбокс, YouTube
├── assets/favicon.svg
└── assets/images/            # реальные и будущие фотографии
```

## Что заменить перед отправкой заказчику/работодателю

- При необходимости уточнить названия серий, авторские кредиты и добавить новые фотосессии.
- Идентификаторы YouTube-видео и подписи к видеоработам, если понадобятся уточнённые названия.
- Контакты.
- Тексты проектов (только подтверждённые результаты и роли).
- При желании добавить более подробные кейсы.

На текущем этапе сайт готов технически для размещения на GitHub Pages, содержит **9 загруженных фотографий и 3 визуальные серии**. Видеоролики уже заполнены восемью YouTube Shorts, контакты остаются пустыми. Никакие несуществующие проекты, ссылки, контакты или YouTube-видео не выданы за реальные.
