# Визуальные референсы: как показывать фотосессии

Изображения чужих авторов не включены в сайт, ссылки оставлены только для вдохновения.

## 1. Editorial archive — журнальная серия

Референс: https://www.behance.net/gallery/201812475/Portfolio-website-for-photographer-Web-Design

- Главная обложка фотосессии на всю ширину или 60–70% контента.
- Затем пара кадров: крупный портрет + деталь.
- Дальше кадр на всю ширину с атмосферой или локацией.
- Последние 2–3 кадра создают визуальное завершение истории.

**На сайте:** выберите `Editorial`.

## 2. Asymmetric mosaic — разновысокая сетка

Референсы:
https://dribbble.com/shots/26503598-Photography-Portfolio-Website
https://hellovlad.com/ulrich-knoblauch

- Вертикальные и горизонтальные изображения чередуются.
- Необязательно одинаковое количество кадров в каждой строке.
- Хорошо работает на главной странице фотопортфолио и в большом архиве.

**На сайте:** выберите `Mosaic`.

## 3. Contact sheet — лист отбора

Референс: https://www.monashee.org/marketing-and-photography-portfolio-examples/photography-portfolio-review-tanya-goehring

- 9–16 небольших кадров одной съёмки, одинаковые отступы.
- Можно показывать разные эмоции и ракурсы, но без 20 почти одинаковых фотографий.
- Чёрная или молочная подложка подчёркивает цветовую серию.

**На сайте:** выберите `Contact sheet`.

## 4. Fashion minimal — минимум интерфейса

Референс: https://www.framer.com/marketplace/templates/iris-wade/

- Один кадр — один смысловой акцент.
- Много воздуха, небольшой набор метаданных.
- Лаконичный стиль без лишних анимаций.

## Рекомендация

Разделить сайт на **страницу-архив** фотосессий с красивыми обложками и **отдельные фотоистории**.
Текущая версия содержит фотоисторию с выбором трёх раскладок. После наполнения реальными съёмками можно добавить отдельные URL для каждой серии, например `photos/portrait-01.html`, без сервера — это обычные HTML-файлы.

Оптимальный порядок 8–10 фотографий внутри одной серии:
`hero → общий план → крупный портрет → деталь → сюжет → портрет → интерьер/локация → финальный кадр`.

Для мобильного экрана ключевые портреты лучше показывать по одному на строку, без чрезмерно мелких миниатюр.

## Атрибуция

Все 10 фотографий предоставленных серий сняты Алиной Медведевой. В интерфейсе указывается «Фотограф: Алина Медведева», текст галереи описывает работу автора с композицией, светом и построением портретов. На публичном сайте не следует приписывать авторство образов или стилизации без отдельного подтверждения.
